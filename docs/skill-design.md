# 전투 설계 (평타 3타 + 고유스킬 / 궁극기, 무기는 수치)

> 상태: **확정, 구현됨.** 애니메이션 클립만 아직 3타가 전부 같은 모션이다.
> 작성일: 2026-09-16

## 한 줄 규칙

> **타격은 전부 캐릭터 것, 무기는 숫자만 준다.**

평타 3타·고유스킬·궁극기는 모두 캐릭터에 귀속된다. 무기를 바꿔도 무엇을 어떻게 치는지는 안 바뀐다. 바뀌는 건 얼마나 세게, 얼마나 멀리, 얼마나 빨리 치느냐뿐이다.

## 용어

| 말 | 뜻 |
|---|---|
| **평타** | 자동으로 나가는 기본 공격. 3타 콤보. 스킬이라 부르지 않는다 |
| **고유스킬** | 평타 3타를 마친 뒤 나가는 네 번째 타. 캐릭터마다 다르다 |
| **궁극기** | 사이클 밖에서 따로 도는 캐릭터 기술. 버튼으로 쓴다 |
| **무기** | 공격력·사거리·간격. 공격력은 성장한다 |

"무기스킬"이라는 말은 쓰지 않는다. 무기는 기술을 갖지 않는다.

## 공격 사이클

```
평타1 → 평타2 → 평타3 → 고유스킬 → 평타1 → …
   └─ 콤보 유지 시간(1.2초) 안에 다음 타격이 없으면 평타1 로 리셋
```

- 네 타 모두 **무기의 간격**을 따른다. 사이클 내내 일관되다.
- 궁극기는 사이클에 끼지 않는다. 자기 쿨타임으로 따로 돌고, 써도 콤보 위치가 안 바뀐다.
- 적은 사이클이 평타 1타뿐이고 궁극기도 없다.

## 피해 계산

```
피해 = 무기 공격력 × 타격 배수
```

| 타격 | 배수 초안 |
|---|---|
| 평타1, 평타2 | ×1.0 |
| 평타3 | ×1.2 |
| 고유스킬 | ×1.6 ~ 2.0 (캐릭터별) |
| 궁극기 | ×3.0 ~ 3.5 (캐릭터별) |

타격은 수치를 들고 있지 않다. 배수만 들고, 무기 공격력에 곱한다. 그래서 무기 공격력이 오르면 모든 타격이 같이 세진다 — 이게 무기 성장의 게임성이다.

## 무기

무기 한 자루는 `WeaponInfo`다.

| 항목 | 내용 |
|---|---|
| 계열 | 검류 · 도끼류 · 활류 · 지팡이류 |
| 공격력 | 성장으로 오른다 (지금은 고정값) |
| 사거리 | 계열·무기별 |
| 간격 | 계열·무기별. 사이클 전체의 박자 |

계열은 지금은 분류만 한다. 나중에 **계열별 상태이상**(도끼류는 경직, 지팡이류는 둔화 같은)을 붙일 근거다.

지금 있는 무기: 낫(도끼류)·검(검류)·지팡이(지팡이류)·맨손·고블린 몽둥이·오우거 몽둥이. 활류는 아직 없다.

## 수치가 사는 곳

전부 코드 선언 테이블이다. ScriptableObject는 쓰지 않는다.

| 테이블 | 내용 |
|---|---|
| `Data/AttackPlans` | 캐릭터별 사이클(평타 3타 + 고유스킬)·궁극기, 무기별 `WeaponInfo` |
| `Data/EquipmentPlans` | 장비 ID → 부위 |
| `Data/CharacterProfiles` | 이름·초상화·고유색 |
| `HeroManager.Plans` | 히어로 HP·이속·기본 한 벌 |

## 구현 구조

```
Character
 ├ Attacks : CharacterAttacks   사이클 4타 + 궁극기
 ├ NextAttack : Attack          지금 나갈 타격 (AttackCycle 이 결정)
 ├ AttackRange                  = 무기 사거리
 ├ DamageOf(attack)             = 무기 공격력 × attack.PowerMultiplier
 ├ AttackCooldown               사이클 쿨타임 (= 무기 간격)
 └ UltimateCooldown             궁극기 쿨타임 (= attack.Cooldown)

Attack                          이름 · 모션 · 배수 · (궁극기면) 쿨타임
AttackCycle                     사이클 4타를 순서대로 돌리고, 끊기면 1타로
Weapon.Info : WeaponInfo        계열 · 공격력 · 사거리 · 간격
```

컨트롤러는 `character.AttackRange`로 사거리를 보고, `UseAttack(character.NextAttack)`으로 내보내고, `character.DamageOf(attack)`으로 피해를 준다.

## 애니메이션

- 평타 클립은 `Attack1` / `Attack2` / `Attack3`. 히어로는 셋 다, 적은 `Attack1`만.
- **지금은 3타가 전부 같은 모션이다.** 1타를 복사해 둔 상태고 차이는 나중에 준다. 카게는 `KageBuilder`가 복사본을 만든다.
- 고유스킬은 전용 클립이 없어서 `Attack3`를 빌려 쓴다.
- 궁극기는 `Ultimate`.

## 남은 것

- **3타 모션 차이** — 지금은 복사본.
- **고유스킬 전용 모션** — 캐릭터별 클립.
- **무기 공격력 성장** — 지금은 테이블 고정값. 성장 수치를 어디에 저장할지는 세이브 설계와 같이.
- **계열별 상태이상** — `CharacterStatus`는 만들어져 있고 아직 안 물렸다.
- **맨손** — `BareHands`를 검류로 분류해뒀는데 어색하다. 무기 부위가 비는 걸 허용할지 같이 결정.
