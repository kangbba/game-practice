# 전투 설계 (평타 4콤보 / 스킬 / 궁극기, 무기는 수치)

> 상태: **확정, 구현됨.**
> 작성일: 2026-09-16 · 개정: 2026-09-17 (고유스킬 폐지, 평타 4콤보 + 쿨타임 스킬로 변경)

## 한 줄 규칙

> **타격은 전부 캐릭터 것, 무기는 숫자만 준다.**

평타 4콤보·스킬·궁극기는 모두 캐릭터에 귀속된다. 무기를 바꿔도 무엇을 어떻게 치는지는 안 바뀐다. 바뀌는 건 얼마나 세게, 얼마나 멀리, 얼마나 빨리 치느냐뿐이다.

## 용어

| 말 | 뜻 |
|---|---|
| **평타** | 자동으로 나가는 기본 공격. 4타 콤보를 반복할 뿐이다. 스킬이라 부르지 않는다 |
| **스킬** | 쿨타임 기술. 궁극기와 같은 꼴이고 쿨이 짧을 뿐이다. 캐릭터마다 다르다 |
| **궁극기** | 쿨타임 기술. 스킬보다 쿨이 길고 세다 |
| **무기** | 공격력·사거리·간격. 공격력은 성장한다 |

"고유스킬"(사이클 네 번째 타)이라는 개념은 폐지했다. "무기스킬"이라는 말도 쓰지 않는다 — 무기는 기술을 갖지 않는다.

## 공격 사이클

```
평타1 → 평타2 → 평타3 → 평타4 → 평타1 → …
   └─ 콤보 유지 시간(1.2초) 안에 다음 타격이 없으면 평타1 로 리셋
```

- 네 타 모두 **무기의 간격**을 따른다. 4타를 내면 다음 묶음까지 길게 쉰다.
- 스킬·궁극기는 사이클에 끼지 않는다. 각자 쿨타임으로 따로 돌고, 써도 콤보 위치가 안 바뀐다.
- 스킬·궁극기는 평타 4콤보 **도중에도** 나갈 수 있다 — 진행 중이던 평타 타격 판정을 끊고 즉발한다.
- 적은 사이클이 평타 1타뿐이고 스킬·궁극기가 없다.

## 전투 HUD와 자동전투

- 우측 하단 버튼은 **둘**: 스킬, 궁극기. 각자 자기 쿨타임을 보여준다.
- 평타는 버튼이 없다 — 사거리에 적이 있으면 알아서 4콤보를 돈다.
- 자동전투(입력이 조용한 상태)에서는 스킬·궁극기도 쿨이 돌아오면 그 자리에서 자동으로 나간다. 버튼을 눌러준 것과 같다. 둘 다 준비됐으면 궁극기가 먼저다.

## 피해 계산

```
피해 = 무기 공격력 × 타격 배수
```

| 타격 | 배수 초안 | 쿨타임 초안 |
|---|---|---|
| 평타1, 평타2 | ×1.0 | — |
| 평타3, 평타4 | ×1.2 | — |
| 스킬 | ×1.6 ~ 2.0 (캐릭터별) | 4.5 ~ 6초 |
| 궁극기 | ×3.0 ~ 3.5 (캐릭터별) | 9 ~ 12초 |

타격은 수치를 들고 있지 않다. 배수만 들고, 무기 공격력에 곱한다. 그래서 무기 공격력이 오르면 모든 타격이 같이 세진다 — 이게 무기 성장의 게임성이다.

## 무기

무기 한 자루는 `WeaponInfo`다.

| 항목 | 내용 |
|---|---|
| 계열 | 검류 · 도끼류 · 활류 · 지팡이류 |
| 공격력 | 성장으로 오른다 (지금은 고정값) |
| 사거리 | 계열·무기별 |
| 간격 | 계열·무기별. 사이클 전체의 박자 |

계열은 지금은 분류만 한다. 나중에 **계열별 상태이상**(도끼류는 경직, 지팡이류는 둔화 같은)을 붙일 근거다.

지금 있는 무기: 낫(도끼류)·검(검류)·지팡이(지팡이류)·맨손·고블린 몽둥이·오우거 몽둥이. 활류는 아직 없다.

## 수치가 사는 곳

전부 코드 선언 테이블이다. ScriptableObject는 쓰지 않는다.

| 테이블 | 내용 |
|---|---|
| `Data/CombatPlans` | 캐릭터별 평타 4콤보 + 스킬 + 궁극기(+ 궁극기 연출 ID) |
| `Data/EquipmentPlans` | 장비 ID → 장착 자리, 무기별 `WeaponInfo` ([장비 설계](equipment-design.md)) |
| `Data/CharacterProfiles` | 이름·초상화·고유색 |
| `HeroManager.Plans` | 히어로 HP·이속·기본 한 벌 |

## 구현 구조

```
Character.Combat : CharacterCombat   CombatPlan 을 받아 만들어진다 (캐릭터별 서브클래스 없음)
 ├ Cycle : AttackCycle               평타 4콤보를 순서대로 돌리고, 끊기면 1타로
 ├ Skill / Ultimate : CharacterSkill 쿨타임 기술. 없는 캐릭터(적)는 null
 ├ AttackCooldown                    평타 간격 (= 무기 간격)
 ├ SkillCooldown / UltimateCooldown  기술별 쿨타임 (= CharacterSkill.Cooldown)
 └ UseSkill() / UseUltimate()        공용 Cast — 평타 판정을 끊고 즉발

CharacterSkill : BasicAttack         이름 · 모션 · 배수 + 쿨타임
```

컨트롤러(`HeroController`)는 사거리 안에서 평타를 자동으로 돌리고, 자동전투면 쿨이 돌아온 궁극기→스킬 순으로 대신 눌러준다. 버튼 입력도 같은 `UseSkill`/`UseUltimate`를 부른다.

## 애니메이션

- 평타 클립은 `Attack1` ~ `Attack4`. 히어로는 넷 다, 적은 `Attack1`만.
- `Attack4`는 큰 보폭과 회전·내려찍기를 쓰는 전용 마무리 모션이다.
- 스킬·궁극기는 전신 이동과 무기 확대를 함께 사용한다. 기본 장착 무기 기준 시각적 궤적 반경은 스킬 7, 궁극기 10이다. 피해 판정 사거리는 기존 무기 수치를 따른다.
- 스킬은 `Skill`, 궁극기는 `Ultimate`. 궁극기는 깊은 준비 자세 → 도약 → 공중 정점 → 급강하 → 착지 강타로 구분된다.
- 스킬·궁극기 재생 중 자동 이동·평타·다른 기술이 모션을 덮어쓰지 않는다. 타격은 스킬의 첫 큰 베기, 궁극기의 착지 시점에 맞춘다.

## 남은 것

- **무기 공격력 성장** — 지금은 테이블 고정값. 성장 수치를 어디에 저장할지는 세이브 설계와 같이.
- **계열별 상태이상** — `CharacterStatus`는 만들어져 있고 아직 안 물렸다.
- **맨손** — `BareHands`를 검류로 분류해뒀는데 어색하다. 주장비 자리가 비는 걸 허용할지 같이 결정.
