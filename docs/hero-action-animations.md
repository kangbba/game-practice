# 영웅 공격 모션

세 영웅의 `Attack1 / Attack2 / Attack3 / Skill / Ultimate` 15개 클립을 각기 다른 자세로 제작했다.

| 영웅 | 동작 방향 |
| --- | --- |
| Kage | 낮은 전진 베기 → 반대로 올려베기 → 크게 디디는 마무리. 스킬은 전진 베기 뒤 다시 몸을 낮춰 올려벤다. |
| Aldric | 무게를 뒤에 모았다 앞발에 싣는 큰 궤적. 스킬은 첫 베기 후 무기를 다시 들어 강하게 내리친다. |
| Nyx | 발이 따라 올라오는 부유 자세와 무기를 내밀 때 몸이 받는 반동. 스킬은 끌어모으기와 방출을 두 번 잇는다. |

## 모션 제작

- 몸통, 어깨, 팔꿈치가 차례로 따라 움직인다. 머리는 시선을 유지하고 머리카락·망토·스카프는 지연과 관성을 가진다.
- 발끝 목표 위치에서 다리 각도와 길이를 계산해 지지하는 발과 내딛는 발을 구분한다. 회수할 때 앞발을 들어 되돌린다.
- 칼끝의 방향을 팔 관절 각도의 합과 별도로 설계해 준비 → 베기 → 관성으로 이어지는 궤적을 만든다.
- 준비·회수에는 부드러운 보간, 베기에는 빠른 통과, 타격 자세에는 짧은 정지를 사용한다.
- 기존 한 덩어리 다리 스프라이트를 사용한다. 새 무릎 리그나 새 그림을 추가한 작업은 아니다.
- 60Hz로 계산한 Transform 커브를 오차 범위 안에서 정리해 `.anim`에 저장한다. 런타임 보정 컴포넌트는 필요하지 않다.

기존 클립 길이(0.55 / 0.60 / 0.68 / 1.05 / 1.80초)와 GUID를 유지한다. 전투 판정·쿨타임·자동 궁극기·CharacterMotion의 재생 로직은 이 작업의 변경 대상에서 제외했다.

## 미리보기

- `★Sayne★ > 영웅 > 애니메이션 프리뷰`: Kage / Aldric / Nyx 선택, 시간 슬라이더, 좌우 반전.
- `★Sayne★ > 영웅 > 전신 공격 애니메이션 재빌드`: 15개 클립을 다시 제작한다. 수작업으로 수정한 클립은 덮어쓰므로 필요할 때만 실행한다.
- `HeroActionAnimationBuilder.BuildAndReview`: 임시 폴더 `SayneHeroActionReview`에 포즈 시트와 30fps 연속 프레임을 출력한다.
