## 들어 있는 것

- 반자동 전투: 평타와 스킬은 자동으로 나가고, 조이스틱으로 움직입니다. 조이스틱을 놓으면 가까운 적에게 돌진합니다.
- 궁극기: 컷인, 무대 연출, 타격 순서로 진행됩니다. 무기마다 궁극기가 다릅니다.
- 스테이지와 웨이브, 보스, 퀘스트
- 영웅 셋(알드릭, 닉스, 카게) 편성 교체, 부위별 장비, 골드로 사는 성장

## 구조

- `UnityProject/GamePractice/Assets/Game`: 게임 코드와 에셋. 기능별 폴더(`Characters`, `Equipment`, `Battle`, `UI` 등)에 코드, 프리팹, 그림을 함께 둡니다.
- `UnityProject/GamePractice/Assets/SayneAssets`: 게임과 상관없이 다시 쓰는 부품. 아래 참고.

## 설계 중점

- 수명 단위의 매니저 구성 (게임 / 전투)
- 전투 → 게임 방향의 단방향 의존
- 로드가 끝난 에셋 묶음 단위의 전달
- 프리팹이 정하는 모양, 값만 다루는 스크립트
- 게임 코드와 분리된 재사용 부품

## 재사용 부품 (SayneAssets)

게임 코드를 참조하지 않아서, 폴더째 복사하면 다른 프로젝트에서도 씁니다. 모양은 프리팹이 정하고, 스크립트는 값만 받아 그립니다.

| 부품 | 하는 일 |
|---|---|
| 조이스틱 | 누른 자리에 뜨는 플로팅 조이스틱. 방향만 알려 주고, 무엇을 움직일지는 모릅니다. |
| HP바 | 머리 위를 따라가는 화면 바, 발밑에 붙는 월드 바. 현재값과 최대값을 구독해 그리고, 줄어드는 연출이 들어 있습니다. |
| 말풍선 | 화면 아래 대사, 머리 위 말풍선. 한 글자씩 찍고, 눌러서 넘기거나 알아서 사라집니다. 게임이 멈춘 동안에도 돕니다. |
| 데미지 숫자, 게이지 | 떠올랐다 사라지는 숫자, 9슬라이스를 유지한 채 차오르는 게이지 |
| 페이즈 | 페이즈가 다음 페이즈를 돌려주며 흐르는 상태 머신. 페이즈가 나가면 그 안의 구독과 비동기 작업이 같이 정리됩니다. |
| 매니저 기반 | 매니저 수명(`ManagerBase`), 같은 수명끼리 묶어 여닫는 스코프, 로드를 마친 묶음만 넘겨주는 에셋 그룹, 쿨타임 타이머 |
| 오브젝트 이미지 | 프리팹을 UI 위에 그림 한 장처럼 비춥니다. 장비·편성 창의 캐릭터 인형이 이걸 씁니다. |
| 뷰 | 카메라를 향하는 빌보드, 패럴랙스 배경 |

## 앞으로

## 실행

Unity 6000.3.2f1로 `UnityProject/GamePractice`를 열고 플레이합니다. 처음 열면 게임 씬(`Assets/Scenes/Game.unity`)이 자동으로 열립니다.
